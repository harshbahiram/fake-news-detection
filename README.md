# fake-news-detection

An end-to-end Data Science and Machine Learning project that uses Natural Language Processing (NLP) techniques to classify news articles based on patterns learned from real and fake news datasets.

## Objectives

- Explore and analyze news article datasets.
- Perform text preprocessing using NLP.
- Extract numerical features using Bag of Words and TF-IDF.
- Train and compare multiple machine learning algorithms.
- Evaluate model performance using appropriate classification metrics.
- Develop an interactive application for news classification.

## Technologies

- Python
- NumPy and Pandas
- Matplotlib and Seaborn
- NLTK
- Scikit-learn
- Jupyter Notebook
- Streamlit

## Project Structure

- `data/` – Dataset storage
- `notebooks/` – Data analysis and ML experiments
- `src/` – Reusable Python modules
- `models/` – Trained model artifacts
- `app/` – Application code
- `reports/` – Analysis outputs and visualizations
- `tests/` – Test cases

## Project Status

Currently in Phase 1: Repository and project initialization.

## Disclaimer

This project classifies articles based on patterns learned from its training dataset. It does not independently verify the factual accuracy of news claims.
